DeepSeek Sidebar 隐私政策

最后更新：2026年8月26日

概述

DeepSeek Sidebar（以下简称"本扩展"）尊重您的隐私。本扩展不向开发者或第三方分析服务收集、存储或传输个人数据。

数据收集

本扩展不收集任何用户数据，包括但不限于：

  • 个人信息
  • 浏览历史
  • Cookie 或跟踪标识符
  • 输入内容或对话记录

本地存储

本扩展使用 chrome.storage.local 在您的设备本地按浏览器标签页保存缩放比例、上次选择的应用、Harness 对话路由、Harness 地址、可选 bridge token 和 Harness 会话编号。该数据仅存储在您的浏览器中，不会发送到扩展作者的服务器。

当您点击选择页面元素按钮时，本扩展会在当前标签页中执行一次性脚本以读取选中元素的可见文本。文本只显示在本地页面阅读器中，或由您主动复制；本扩展不会把选中内容填充到 DeepSeek、ChatGPT 或其他 AI 网站的输入框。

原生模式下，侧边栏直接加载您配置的 DeepSeek Harness 页面，用户任务通过 WebSocket bridge 发送给该 Harness；只有当 Harness 请求 browser_snapshot、browser_get_text 或其他浏览器工具时，扩展才读取当前页面并返回结构化文本。页面文本不会截图，也不会经过第三方 AI 网站的输入框。兼容模式下，页面快照会作为 API 请求的一部分发送到您配置的 Harness 地址。该地址可以是本机或您控制的局域网/远程服务；本扩展不会把这些内容发送到开发者的服务器。

第三方服务

本扩展在侧边栏中加载第三方 AI 聊天网站（DeepSeek、千问、智谱、Kimi、ChatGPT、Gemini）。这些网站由各自运营商独立运营，其自身的隐私政策适用于您在该网站上的活动。本扩展不控制也不负责这些网站的数据处理行为。

DeepSeek Harness 由您自行运行或配置。Harness 对页面快照、任务文本和执行记录的处理取决于其自身配置与隐私政策。

权限说明

  • sidePanel — 在 Chrome 侧边栏中展示 AI 聊天站点和您配置的本地 Harness 页面
  • activeTab — 用户点击扩展后临时授权选择当前标签页中的页面元素
  • storage — 在本地保存按标签页隔离的侧栏状态和连接设置
  • tabs — 查询当前标签页，并在 HTTP 兼容模式下创建后台 Harness 宿主页面
  • scripting — 为页面选择器和 Harness 的 browser 工具注入页面桥接脚本
  • debugger — 为 Harness 提供受控的 Chrome DevTools Protocol 调用入口
  • webNavigation — 枚举当前标签页的主文档与 iframe，让原生网页工具按 frame 路由
  • <all_urls> — 读取和操作当前普通网页，并访问您配置的 Harness 地址；安装或更新扩展时，请在 Chrome 权限提示中允许访问网站
  • declarativeNetRequest — 移除 X-Frame-Options / Content-Security-Policy 响应头，使 AI 聊天网站能在侧边栏 iframe 中正常加载
  • declarativeNetRequestWithHostAccess — 修改千问（qianwen.com）侧边栏 iframe 的请求头（User-Agent、sec-ch-ua-*），使其正确渲染移动版页面
  • host_permissions — 访问 AI 站点、localhost 和 127.0.0.1 上的 Harness 服务以实现上述功能

变更

如本隐私政策发生变更，我们将在此页面更新最后更新日期。
